# Симулятор кота

Браузерная 2D-игра: кот ходит по квартире и ищет места, где поспать.
Карандашный рисунок на бумаге, строго ортогональное построение, никакой перспективы.

Полный дизайн-документ — `C:\dc\cat-game-plan (1).md`.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка собранной версии (ведёт себя иначе, чем dev — проверять обязательно):

```bash
npm run build && npm run preview
```

## Управление

| Что | Как |
|---|---|
| Идти | стрелки ← → или A / D |
| Идти к точке | клик или тап по комнате |
| Лечь | пробел или клик по коту |
| Проснуться / встать | любая клавиша или клик |
| Альбом поз | **Tab** или кнопка в правом верхнем углу |
| Звук: громкость и выключение | кнопка в правом верхнем углу, **M** — выключить, **Esc** — закрыть |
| Отладка (fps, координаты, состояние, таймер бездействия) | клавиша **I** |
| Вызвать фоновое событие (только в dev) | клавиша **F** |

Клавиша всегда сильнее клика: нажатие отменяет цель, к которой шёл кот.

## Что готово

**Фазы 0-1 — комната и движение**

- Мир 2560×540 при окне 960×540, камера едет за котом: мёртвая зона, плавное следование, опережение взгляда при развороте.
- Пять слоёв параллакса: вид в окно 0.25 → стена 0.8 → пол и мебель 1.0 → кот 1.0 → передний план 1.15.
- Зерно бумаги отдельным экранным слоем (`scrollFactor 0`, `MULTIPLY`) — лист не двигается, движется рисунок под ним.
- Вся графика генерируется кодом: дрожащая линия, штриховка, шум бумаги, силуэт кота. Из бинарных файлов в игре только звук.

**Фаза 2 — первое место для сна**

- Таблица мест `src/data/spots.js`; `SpotManager` ищет ближайшее доступное и подтягивает к нему цель клика.
- Полный цикл: `PROMPT` → `ENTERING` → `SLEEPING` → `WAKING`. Кот доходит, ложится, мурчит, потягивается и встаёт.
- Позы кота — интерполяция между «стоя» и «лёжа», отдельных рисунков на каждое состояние не нужно.
- Мурчание в два слоя (гул + дыхание) с fade in 800 мс и fade out 600 мс. Петли синтезируются в буферы на старте — звуковых файлов пока тоже нет.
- `TitleScene`: без клика по нему браузер не разрешит звук.
- `UIScene`: подсказка над котом, отдельной сценой поверх игры.

**Фаза 3 — утыкание в стену**

- `IdleSystem`: 25 секунд без ввода — и кот сам уходит к ближайшему углу комнаты, садится спиной к игроку и замирает. Любой ввод по дороге возвращает управление.
- Отдельный силуэт со спины: сгорбленная спина, уши, хвост сбоку.
- Микрособытия раз в 4-12 секунд — дёрнулось ухо, повернул голову, повёл хвостом. Интервал растёт с каждым разом и упирается в 20 секунд: кот визуально застывает.
- Фоновое событие: раз в 2-5 минут по стене проползает муха короткими перебежками и улетает. Идёт только пока кот залип — это награда терпеливому игроку.
- У мира появились нарисованные углы: без них кот утыкался в пустоту.

**Фаза 4 — наполнение комнаты**

- Четыре места для сна с разными позами: коврик (растёкся), комод под окном (батон), диван (на боку), батарея (клубком). На комод и диван кот запрыгивает — у места есть высота поверхности.
- Время суток: 24 игровых часа за 6 реальных минут. Ночь сделана **не затемнением**, а сдвигом тона бумаги от тёплого к холодному и падением контраста — экран остаётся светлым в любое время.
- Места открываются по времени: подоконник 8-16, диван 12-22, батарея с 18 до 6 (окно пересекает полночь), коврик всегда. Закрытое место не исчезает: сердечко гаснет до призрака, а под ним идёт обратный отсчёт до открытия.
- Альбом поз по Tab: найденные позы показаны рисунком, ненайденные — силуэтом. Прогресс хранится в localStorage.
- Плашка «новая поза» при первом открытии.

**Фаза 5 — полировка и релиз**

- Решение по графике: комната остаётся процедурной, это финальный вид, а не заглушка. Пункт про атласы отпал вместе с бинарными ассетами — паковать нечего.
- Кот переведён на обведённый силуэт: ходьба и стойка с фазами шага, четыре нарисованные позы сна с укладыванием и пробуждением, сидение анфас с четырьмя микрособытиями.
- Фон комнаты: низкий гул и тиканье часов.
- Звук вынесен в файлы: OGG для всех браузеров и MP3 для Safari, который OGG не понимает. Синтез переехал из игры в `tools/synth.cjs` и теперь генерирует эти файлы — исходником звука остаётся код, а не сами файлы.
- Настройки звука: пять ступеней громкости и выключение, с экранными кнопками — на телефоне ни Tab, ни M нажать нельзя. Сохраняются в localStorage.
- Сердечки над местами для сна: видно, где коту можно лечь. Под закрытым местом идёт таймер, и считается он в реальных минутах, а не в игровых часах — часов в комнате нет, и «с 12:00» игроку ничего не сказало бы. Под котом, который уже лёг, метка прячется.
- Портрет на телефоне: подсказка повернуть экран вместо игры, ужатой в полоску.
- Релизный архив собирается своим инструментом (см. ниже).

## Правила, которые легко нарушить

1. **Зерно бумаги ни в одном спрайте.** Только верхним экранным слоем — иначе оно поедет вместе с котом.
2. `roundPixels: false`, `antialias: true`, `pixelArt: false`. Противоположно обычным настройкам 2D-игр: при дробных `scrollFactor` округление позиций заставит слои дёргаться.
3. **Никакой физики.** Движение — `x += speed * dt`.
4. **Данные отдельно от логики.** Ни одна система не должна знать конкретных `id` мест для сна.
5. **Штрихи собираются в общие пути.** `generateTexture` рисует через Canvas2D, и каждый отдельный `stroke()` там дорог: на отдельных вызовах слой пёкся 8 секунд вместо 15 мс.
6. Ширина слоя = `WIDTH + (WORLD_WIDTH - WIDTH) * factor`, иначе у края мира покажется пустота.
7. **Громкость в Phaser 3.90 нельзя ни твинить, ни задавать через менеджер.** У звука сеттер `volume` работает, а геттер всегда возвращает 1 — твин берёт стартовое значение оттуда, и «плавное появление» превращается в падение с полной громкости. У менеджера сцены свойства `volume` и `mute` расходятся с реальностью так же. Поэтому громкость ведётся своим множителем: настройки кладут его в реестр, `AudioManager` домножает каждый звук вручную через `setVolume`.
8. **Одноразовые действия — на событии, а не на `JustDown`.** Если нажатие и отпускание попали в один кадр (подтормаживающая вкладка, быстрый тап), опрос теряет нажатие.
9. **Клавиши и кнопки интерфейса не считаются вводом.** Tab, Esc, M и клики по кнопкам в углу не будят кота: иначе взгляд на альбом или правка громкости поднимали бы его с места.
10. **Ночь — не затемнение.** Тон бумаги уезжает в холодный серый, тёмные тона подтягиваются вверх слоем в режиме SCREEN. Затемнение превратило бы бумагу в грязь.

## Сборка релиза

```bash
npm run build && node tools/make-zip.cjs dist cat-game-itch.zip
```

Готовый `cat-game-itch.zip` заливается на itch.io как HTML-игра: `index.html` лежит в корне архива, пути внутри относительные. Размер около 340 КБ, почти целиком Phaser.

Стандартные средства не подошли и потому не используются: `Compress-Archive` пишет пути через обратный слэш, на котором itch.io спотыкается, а `bsdtar -a` молча делает tar вместо zip.

## Инструменты

Не входят в игру, нужны для работы над графикой:

```bash
node tools/trace-cat.cjs C:/dc/cat5.png --preview   # обводка силуэта в контур
node tools/preview-cat.cjs out.png 3                # кадры кота без браузера
node tools/preview-cat.cjs out.png 3 --pose=loaf:4  # укладывание по шагам
node tools/preview-cat.cjs out.png 3 --front        # кот анфас
node tools/make-audio.cjs                           # перегенерировать звук
```

Нормализация в синтезе стоит **после** огибающей, а не до. Наоборот было ошибкой: пульс мурчания в среднем сильно меньше единицы, и готовый файл выходил втрое тише своего запаса. У пульса высокое дно (0.34), иначе между ударами нет корпуса и мурчание слышно как редкие щелчки.

Звук пересобирается из `tools/synth.cjs` в OGG и MP3 через `ffmpeg-static` — он стоит в dev-зависимостях и в игру не попадает. Кодировщик вызывается с тегом Xing: без него MP3-декодер не знает про задержку кодировщика и на стыке петли слышен щелчок. Проверено: и OGG, и MP3 декодируются ровно в 144000 отсчётов на трёхсекундной петле, добавочной тишины нет.

Оффлайн-превью появилось не от хорошей жизни: панель браузера не вызывает `requestAnimationFrame`, пока окно не на переднем плане, и проверять графику в ней невозможно. Рисовальному коду подсовывается заглушка Graphics, полигоны растеризуются в PNG.
